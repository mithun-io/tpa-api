TPA PLATFORM - API ENDPOINTS

AUTH MODULE (/api/v1/auth)
--------------------------
POST /api/v1/auth/customer/register - Customer registration (Sends OTP)
PATCH /api/v1/auth/customer/verify - Verify customer OTP
POST /api/v1/auth/patient/register - Patient registration (Sends OTP)
PATCH /api/v1/auth/patient/verify - Verify patient OTP
POST /api/v1/auth/carrier/register - Carrier registration (Sends OTP)
PATCH /api/v1/auth/carrier/verify - Verify carrier OTP
PATCH /api/v1/auth/resend-otp/{email} - Resend OTP
POST /api/v1/auth/login - User login
PATCH /api/v1/auth/password-change - Change password (Authenticated)
PATCH /api/v1/auth/forget-password/{email} - Forgot password (Sends OTP)
PATCH /api/v1/auth/password-reset - Reset password using OTP
POST /api/v1/auth/refresh - Refresh JWT token

CLAIM MODULE (/api/v1/claims)
----------------------------
POST /api/v1/claims - Create claim (CUSTOMER)
GET /api/v1/claims/{id} - Get claim details (ADMIN, EMPLOYEE, CARRIER, CUSTOMER)
GET /api/v1/claims/search - Search claims with filters
GET /api/v1/claims - Get all claims (ADMIN) or user's claims (CUSTOMER)
GET /api/v1/claims/{id}/export - Export claim as PDF
GET /api/v1/claims/{id}/audits - Get claim audit logs
GET /api/v1/claims/{id}/timeline - Get claim timeline
PUT /api/v1/claims/{id}/carrier-approve - Carrier approval
DELETE /api/v1/claims/{id} - Delete claim (ADMIN, CUSTOMER)

ADMIN MODULE (/api/v1/admin)
---------------------------
GET /api/v1/admin/users - List users
PATCH /api/v1/admin/users/{id}/block - Block user
PATCH /api/v1/admin/users/{id}/unblock - Unblock user
GET /api/v1/admin/customers - List customers
GET /api/v1/admin/claims - List all claims
PATCH /api/v1/admin/claims/review - Review claim
POST /api/v1/admin/claims/review - Alternative review endpoint
PATCH /api/v1/admin/claims/{id}/approve - Approve claim
PATCH /api/v1/admin/claims/{id}/reject - Reject claim
GET /api/v1/admin/claims/{id}/ai-summary - Get AI-generated summary
POST /api/v1/admin/claims/{id}/ai-chat - Chat with AI about claim
GET /api/v1/admin/monitoring - System monitoring
GET /api/v1/admin/carriers - List carriers
PATCH /api/v1/admin/carriers/{id}/approve - Approve carrier
PATCH /api/v1/admin/carriers/{id}/reject - Reject carrier
PATCH /api/v1/admin/claims/{id}/assign-carrier - Assign claim to carrier

AI MODULE (/api/v1/ai)
---------------------
POST /api/v1/ai/analyze/{claimId} - Analyze claim documents
POST /api/v1/ai/claims/{id}/generate-summary - Generate claim summary
POST /api/v1/ai/validate-claim - Validate claim data
POST /api/v1/ai/validate-document - Validate uploaded document (Multipart)

ANALYTICS MODULE (/api/v1/analytics)
-----------------------------------
GET /api/v1/analytics/dashboard - Get dashboard stats

CARRIER MODULE (/api/v1/carrier)
-------------------------------
GET /api/v1/carrier/claims - List assigned claims
GET /api/v1/carrier/claims/{id} - Get claim details
PATCH /api/v1/carrier/claims/{id}/validate - Validate claim
PATCH /api/v1/carrier/claims/{id}/approve - Approve claim
PATCH /api/v1/carrier/claims/{id}/reject - Reject claim
PATCH /api/v1/carrier/claims/{id}/remark - Add remark to claim
PATCH /api/v1/carrier/claims/{id}/flag - Flag claim for fraud
GET /api/v1/carrier/claims/{id}/policy-status - Check policy status
POST /api/v1/carrier/claims/{id}/ai-analyze - AI analysis for carrier

DOCUMENT MODULE (/api/v1/documents)
----------------------------------
POST /api/v1/documents/upload - Upload claim document
GET /api/v1/documents/claim/{claimId} - Get documents for claim
GET /api/v1/documents/{id} - Download document
DELETE /api/v1/documents/{id} - Delete document

PAYMENT MODULE (/api/v1/payments)
--------------------------------
POST /api/v1/payments/create-order - Create Razorpay order
POST /api/v1/payments/verify - Verify payment
GET /api/v1/payments/claim/{claimId} - Get payments for claim

NOTIFICATION MODULE (/api/v1/notifications)
-----------------------------------------
GET /api/v1/notifications - Get user notifications
PATCH /api/v1/notifications/{id}/read - Mark notification as read
PATCH /api/v1/notifications/read-all - Mark all as read
